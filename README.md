# GLORIOUS PURPOSE
Add `purpose-is-glorious.mp3` (your licensed copy) and optionally `background.jpg` beside index.html.
Run locally: `cd glorious-purpose && python3 -m http.server 8000` then open http://localhost:8000
Deploy: drag the folder into Netlify Drop, or push to GitHub and enable GitHub Pages / Cloudflare Pages / Vercel (static, no build).
